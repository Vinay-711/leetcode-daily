# minimum-depth-of-binary-tree

## Approach

I used a Breadth-First Search (BFS) approach to find the shortest path to a leaf node. BFS is ideal here because it explores nodes level by level, ensuring the first leaf encountered is at the minimum depth. Time complexity is O(N) where N is the number of nodes, and space complexity is O(W) where W is the maximum width of the tree.
