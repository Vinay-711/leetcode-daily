# valid-palindrome

[Original practice problem](https://leetcode.com/problems/valid-palindrome/)

Date: 2026-11-09 (Asia/Kolkata). Status: **Accepted**. Platform: **LeetCode**.

## Approach

I used a two-pointer approach to compare characters from both ends of the string. I skip non-alphanumeric characters using Character.isLetterOrDigit and compare characters case-insensitively. Time complexity is O(n) where n is the length of the string, and space complexity is O(1).
