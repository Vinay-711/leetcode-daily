# find-the-closest-palindrome

[Original practice problem](https://leetcode.com/problems/find-the-closest-palindrome/)

Date: 2026-11-14 (Asia/Kolkata). Status: **Accepted**. Platform: **LeetCode**.

## Approach

To find the closest palindrome, we consider candidates generated by modifying the prefix of the number. We generate candidates by taking the prefix, the prefix + 1, and the prefix - 1, then mirroring them. We also include edge cases like 10^k - 1 (e.g., 999) and 10^k + 1 (e.g., 1001). We calculate the absolute difference for each candidate and pick the one with the smallest difference, breaking ties by choosing the smaller value. Time complexity is O(L) where L is the length of the string, and space complexity is O(L).
