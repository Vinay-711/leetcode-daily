# permutations

[Original practice problem](https://leetcode.com/problems/permutations/)

Date: 2026-11-16 (Asia/Kolkata). Status: **Accepted**. Platform: **LeetCode**.

## Approach

I used a backtracking approach to generate all permutations. The algorithm maintains a boolean array to track visited elements and a temporary list to build current permutations. Time complexity is O(n * n!) and space complexity is O(n) excluding the output storage.
